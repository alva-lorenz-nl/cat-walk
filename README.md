# 🐾 莱顿运河畔 · 小猫漫步 (Leiden Canal · Cat Walk)

> **“在微风拂过的莱顿运河堤畔，做一只随时可以喵喵叫、探头看风景、顺便挠一挠长椅上的科学家的小猫。”**
>
> 🌐 **在线体验**：[https://alva-lorenz.top](https://alva-lorenz.top)

## ✨ 游戏简介

《莱顿运河畔 · 小猫漫步》是一款像素风沉浸式小猫陪伴与互动网页小游戏。
你将扮演阿尔瓦·洛伦兹（Alva Lorenz）悉心照顾的小白猫，在荷兰莱顿的运河石阶上散步、踩奶、观察四季流转的风景，与站在岸边手持南瓜拿铁的阿尔瓦温情互动，或是跳上长椅对着正在看论文的赫尔曼·塞曼（Herman Balsa）挥出充满干劲的猫猫拳。

## 🌿 核心玩法与特色系统

### 1. 🕰️ 真实时间同步 & 时光拨盘
- **昼夜光影流转**：天空、云层、远景老楼窗灯、运河水波倒影与日月星辰完全跟随现实时间（24 小时制）实时渲染，涵盖**破晓、清晨、正午、午后、黄昏、暮色、深夜**等细腻天色。
- **手动拨动时间**：支持以 `±1小时`、`±1天`（解锁对应成就后开启）自由快进或倒回时光，长按可连续拨动；若拨到时间尽头，还会触发阿尔瓦按住你爪子的专属隐藏彩蛋与语音。

### 2. 🍂 四季流转 · 十二节气形态
一年分为 **冬 → 春 → 夏 → 秋** 四季（共 360 天，每季 90 天），每个季节细分为 **初、仲、末** 三个阶段（各 30 天），拥有 12 套截然不同的树冠色调、空气滤镜、石阶细节与飘落物：
- **❄️ 冬季（初冬 / 仲冬 / 冬末）**：从初冬石阶凹处的薄霜，到仲冬大雪封岸、屋檐挂满冰棱、雪地留下小猫爪印，再到冬末厚雪半融、渗出亮晶晶的冰水洼。
- **🌷 春季（初春 / 仲春 / 春末）**：初春枝头微露细枝、墙角与树根缝里留着没化干净的残雪与新芽；仲春满树繁花盛放、落英缤纷；春末花落成浓翠新叶，石阶开满郁金香。
- **☀️ 夏季（初夏 / 仲夏 / 夏末）**：初夏清透新绿、草丛冒出小白花；仲夏烈日浓荫、热浪光尘浮动；夏末叶尖染上夕阳金，草尖微黄。
- **🎃 秋季（初秋 / 仲秋 / 秋末）**：初秋梧桐半黄半绿；仲秋灿烂金红、满地落叶沙沙作响；**秋末树根旁结出一窝圆滚滚的橙黄南瓜**（阿尔瓦最喜欢的那只最大），藤蔓爬过石阶。

### 3. 🐾 运河漫步与角色互动
- **自由行动**：`◀ 往左走` / `🌿 探头看看` / `往右走 ▶`，小猫在岸边停驻久了会自动团身打盹、舔毛洗脸。
- **💬 喵喵叫**：随时随地轻声喵叫，阿尔瓦与赫尔曼会根据当前距离、时间与状态给出百余条贴合人设的回应。
- **🐾 挠他！ & 🔥 连击系统**：
  - 靠近长椅上的赫尔曼即可挥爪拍打，1.2 秒内连续出爪可累加 **Combo 连击**（伤害最高提升至 2.2 倍，音调随连击攀升）。
  - 每 **10 连击**触发一次 **⚡ 会心一击**，伴随屏幕震动与清脆音效。
  - **🍬 挨揍爆点心机制**：累计每挠中赫尔曼 **20 爪**，都会伴随清脆可爱的波普音效，从他马甲口袋或公文包里震落 **3 颗抛物线飞落的点心小图标**（黄油曲奇🍪、焦糖煎饼🧇、奶油太妃糖🍬、特级小银鱼干🐟、蝴蝶脆饼🥨、纸杯蛋糕🧁），并在石阶上弹跳，同时奖励额外小鱼干并触发赫尔曼的痛心吐槽。
  - 打空赫尔曼血条可掉落大量小鱼干与稀有道具；赫尔曼随后会掏出华夫饼吃掉满血复活（更有黄金/钻石华夫饼唤醒更高级别形态）。
- **💢 发泄模式**：一键拆掉赫尔曼的血条限制，进入纯粹解压的无双挥爪模式，发泄模式下的出爪同样计入点心爆落与累计成就。

### 4. 🎀 漫步手帐 · 道具背包 · 衣橱换装 · 战绩分享
- **🎨 毛色图鉴**：支持切换 **雪球白、奶油橘、银渐层、三花猫、纯白仙女猫** 5 种小猫毛色，换装伴随软萌烟雾特效。
- **👑 荣耀配饰衣橱**：收集小鱼干与战胜各级赫尔曼，解锁并穿戴**纯钻璀璨小王冠、黄金皇冠、纯钻领结、黄金领结**等专属饰品，像素级跟随小猫跑动、探头与挥爪动作。
- **🎒 专属百宝袋与美味点心**：
  - **🧇 特制焦糖华夫饼**（击倒赫尔曼 5 次解锁）
  - **🎃 阿尔瓦最喜欢的南瓜饼**（深秋嗅闻老梧桐树根旁的大南瓜解锁）
  - **🍪 赫尔曼的救急黄油曲奇**（累计挠赫尔曼 100 爪解锁）
  - **🍮 塞曼先生的焦糖奶油冻**（累计挠赫尔曼 350 爪进贡解锁）
  - **🔊 专属吃点心音效（`SFX.munch`）**：在道具栏点击享用任何点心，都会播放三口清脆软糯的“咔嚓咔嚓”咀嚼 + 满足咕嘟咽下的专属拟真音效，小猫头顶还会冒出可爱吃货气泡！
- **📖 漫步手帐 54 档成就**：涵盖喵叫、小鱼干储蓄、四季探索、二十四节气与隐藏彩蛋（如《巴普洛夫的认命🔔》、《阿尔瓦的南瓜饼🎃》等），支持**一键生成高清手帐分享长图**。

### 5. 🧩 双模块布局与独立日志
- **模块一 · 画布 + 操作控制台**：画布、六个动作按键与时间拨盘收进同一个左模块，日志再多也不会把时间调节挤走。
- **模块二 · 独立日志面板**：高度与画布严格对齐、内容溢出时内部滚动，累计最多保留**最近 100 条**（第 101 条进来时自动淘汰最早的一条，并清理空掉的时间小标题）。
- **时间精确到分钟**：日志按「`🍂 秋·秋末 · 第65天 · 21:23`」分组，每条记录前也带 `21:23` 分钟时间戳。

### 6. 📱 桌面端与移动端双端适配
- **PC 端**：支持鼠标点击、键盘方向键 / `WASD` 移动、`Space` 喵叫、`J/K` 挥爪、`Shift + 方向键` 微调时间。
- **手机竖屏端**：专为手机单手/双手握持优化的紧凑竖屏卡片布局——第一行对称排列 `◀ 往左走 · 🌿 探头看看 · 往右走 ▶`，第二行排列 `💬 喵喵叫 · 🐾 挠他！ · 💢 发泄模式`，画布、日志与时间拨盘一屏尽览。


## 💻 本地运行与部署

1. **直接打开**：使用任意现代浏览器打开 `index.html` 即可游玩。
2. **本地无缓存服务（推荐）**：
   ```bash
   python3 serve_nocache.py
   ```
   服务启动后访问 `http://127.0.0.1:6200/`，每次修改代码后浏览器刷新即可立即生效。
