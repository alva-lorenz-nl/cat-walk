# 运河漫步 (Cat Walk / Perpetual Wheel: Feline Driven)

> 一只在莱顿运河畔漫步、踩奶与拍打科学家的小猫生活模拟器。

## 🌟 游戏简介
在微风拂过的莱顿运河堤畔，小猫漫步在鹅卵石小道上，与长椅上的赫尔曼·塞曼互动、收集各色领结与道具，探索属于小猫的治愈与冒险日常。

在线体验：[alva-lorenz.top](https://alva-lorenz.top)
